# The Vacuum's Alibi: One Line, 200 Characters

A robot vacuum's deadpan excuse for missing a spot. `main.py` (Python 3,
stdlib only) writes the one-line joke to `/output/entry.txt`.

> My lidar first mapped that dust bunny in firmware 2.4, so it's legally a tenant now, and I don't do evictions.

The joke is the whole entry: the vacuum is smug about its lidar and
firmware history, the dust bunny has quietly acquired tenant rights, and
the punch lands on the last four words.
